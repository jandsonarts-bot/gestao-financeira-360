# Gestão Financeira 360

App de controle financeiro: simulador, gastos, leitura de comprovante e extrato, cartões com parcelas, poupança, dívidas do casal, calculadora e QR code.

- docs/: o app web (GitHub Pages ou Firebase Hosting, login Google e Firestore)
- firestore.rules: regras de segurança do banco

App publicado: https://jandsonarts-bot.github.io/gestao-financeira-360/

Dívidas do casal: qualquer pessoa logada consegue ler a coleção dividas. Para uso com mais gente, restrinja por código de convite.
